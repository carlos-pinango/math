# 📚 Ressources de Mathématiques - Secondaire

Ce dépôt GitHub regroupe un ensemble de ressources pédagogiques conçues spécifiquement pour les **élèves du secondaire**. 

## 🎯 Objectif du Projet
L'objectif est d'offrir une plateforme simple et accessible pour aider les élèves à consolider leurs apprentissages. Le contenu est structuré pour faciliter la révision des concepts clés et la réussite des évaluations.

## 🚀 Contenu Disponible
Le site propose des outils et des documents sur plusieurs thématiques.

## 🌐 Consultation en ligne
Grâce à **GitHub Pages**, les ressources sont consultables directement via une interface web fluide et adaptée à tous les écrans (ordinateurs, tablettes et téléphones).
